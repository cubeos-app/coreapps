The catalogue of pre-built docker-compose stacks that CubeOS bundles. 13 coreapps today:

|---|---|
| cubeos-api | Track C — Go HTTP API + WorkflowEngine |
| cubeos-dashboard | Track C — Vue 3 SPA frontend |
| cubeos-docsindex | Track A — Go docs index server |
| cubeos-hal | Track B — Hardware abstraction layer (privileged) |
| chromadb | Vector store (for cubeos-api semantic search features) |
| dozzle | Container log viewer |
| filebrowser | Web-based file manager |
| kiwix | Offline content reader |
| meshsat | Track D — meshsat bridge daemon |
| mosquitto | MQTT broker |
| npm | nginx-proxy-manager reverse-proxy frontend |
| ollama | Local LLM inference (RPi 5 only) |
| pihole | DNS + DHCP (parent Article VI managed-interface gate applies) |
| registry | Local Docker registry — the ONLY pull source per Article C-II |

## Layout

```
coreapps/
├── defaults.env                # non-secret defaults
├── image-versions.env          # pinned tags (Article C-III)
├── scripts/
│   ├── ci-deploy.sh            # rsync → Pi + apply
│   ├── ci-restart.sh           # selective restart
│   ├── smoke-test.sh           # DoD gate (Article C-V)
│   ├── cubeos-watchdog.service # systemd unit (Article C-IV)
│   ├── cubeos-watchdog.timer
│   ├── watchdog-health.sh
│   └── install-watchdog.sh     # called by releases firstboot
├── <coreapp>/
│   ├── README.md               # mandatory (Article C-VIII)
│   ├── appconfig/
│   │   ├── docker-compose.yml  # single source of truth (Article C-I)
│   │   └── ...env files, init scripts...
│   └── data-templates/         # optional — seed data for first-mount
└── ...
```

## Trust boundaries

- All `image:` references → `localhost:5000` ONLY (Article C-II). External registry access only at build time in `releases/` via skopeo.
- Defaults → `defaults.env` (clean). Secrets → `/etc/cubeos/secrets.env` (generated by `releases/firstboot`).
- Watchdog runs as root (systemd) — needs docker socket access.

## Don't

- Don't reference an external registry in any compose file (Article C-II).
- Don't ship a coreapp without README.md (Article C-VIII).
- Don't put secrets in defaults.env or any compose file (Article C-VI).
- Don't delete a coreapp directory without removing it from git (CI tears down on rsync delete).
- Don't skip `smoke-test.sh` (Article C-V).
